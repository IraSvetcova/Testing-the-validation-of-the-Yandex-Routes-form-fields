# Тестирование валидации полей формы "Яндекс Маршруты"

## Цель работы
Необходимо протестировать валидацию полей формы сервиса Яндекс Маршруты.  

### Задачи:
- Проведение тест-анализа требований и составление декомпозиции.  
- Разработка таблицы классов эквивалентности и граничных значений.  
- Создание тест-кейсов на валидацию полей формы. 
- Выполнение тестирования и оформление баг-репортов.
